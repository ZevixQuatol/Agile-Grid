# Task 007：四向 Dock 与厚度配置验证

日期：2026-10-08。对应 [开发计划](./development-plan.md) Task 007。

## 实现

- 顶部 / 底部 / 左侧 / 右侧使用 CSS Grid 的实际布局区，扣除 Dock 后由 ResizeObserver 测量 GridViewport，并复用已完成的容量适配。
- Dock 设置图标提供四向选择。方向在普通模式可切换；厚度只允许编辑模式调整，默认 48px，范围 40–160px，Store 拒绝非整数、非有限值、越界值和普通模式修改。
- 方向 / 厚度变化立即取消 Drag / Resize 临时事务并清除选中项；不把预览布局提交为正式数据。
- 页导航、编辑、辅助线和排布入口复用原有处理函数。紧凑 Dock 把放不下的操作收进设置菜单；菜单与关于面板使用原生 Popover，不引入 UI 依赖。
