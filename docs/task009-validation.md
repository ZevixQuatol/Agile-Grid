日期：2026-10-08。对应 [开发计划](./development-plan.md) Task 009。

## 实现

- 纯 TypeScript serializer 将应用状态显式转为 `version / grid / dock / pages`，只保留声明的 Cell 字段；校验格式版本、配置、约束、唯一 id、正整数矩形与页内重叠。未知字段不进入恢复结果；保留预留的 allowedSizes，但不启用离散尺寸限制。
- 持久化层使用 `agile-grid:v1` 保存已提交配置与布局。先比较配置 / Dock / 布局引用，再比较稳定序列化结果；预览、取消、选择、页码、编辑 / 辅助线状态与无变化提交不写入。
- 客户端恢复完成后才测量 GridViewport；读取保存的 grid / Dock，清除临时交互，从第一页、浏览模式、无选择启动，再复用既有容量适配。自动缩小后的尺寸继续保存，零容量保留数据。
- 无数据时加载并保存 Demo；坏数据与未知版本提示回退，启动适配保留存储原文，首次布局 / 配置更改后保存新数据。读取失败时继续使用内存；写入失败保持当前已提交内存布局并持续提示，下一次成功保存清除提示。
