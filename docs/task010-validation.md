## 动画帧与最终位置专项

在真实 Chrome 中，原生鼠标启动事务后，通过临时 PointerEvent 探针在同一 JavaScript 任务内发送 20 次移动，检查合并与帧前结束：

- 20 次 pointermove 只调度 1 次动画帧预览。
- 帧前 pointerup 提交最后位置：Drag 最终 x=1，右侧 Resize 最终 w=2，底部 Resize 最终 h=2。
- Drag 和 Resize 的待绘制移动后立即 pointercancel，经过两帧仍无预览，保存数据保持不变。

专项探针用于精确控制事件和动画帧顺序；不表示模拟了特定硬件采样率，也不构成本版帧率或大规模性能承诺。
